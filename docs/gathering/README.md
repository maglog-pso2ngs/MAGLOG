# MAGLOG 採取マップ

公開URL：https://maglog-pso2ngs.github.io/MAGLOG/gathering/

MAGLOGのインストールなしで、ブラウザーから利用できます。採取地域・食材・最大6種類の素材で絞り込めます。
地点・地域境界は収集画像等からの推定値です。境界付近は要確認として表示しています。

地図画像：©SEGA / PHANTASY STAR ONLINE 2 NEW GENESIS
参考情報：https://pso2ngs.swiki.jp/index.php?ギャザリング
シンボル：Lucide（Lucide-LICENSE.txt）

座標データはindex.htmlに含まれます。座標のみの更新はindex.htmlの差し替えで反映でき、MAGLOGの再配布は不要です。

リージョンの「全エリア」で分割前の全体マップと全地域の素材地点を表示できます。全エリアでは全地域の素材から最大6種類を選択し、プリセットにも保存できます。
