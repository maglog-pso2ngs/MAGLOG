# MAGLOG

PSO2 NGSのログ監視、チャット読み上げ、ウィジェット表示、スクリーンショット撮影・整理を行うWindows x64アプリです。

このリポジトリでは、MAGLOGの配布ファイルと更新情報を公開します。

## ダウンロード

[Releasesから正式版をダウンロード](https://github.com/maglog-pso2ngs/MAGLOG/releases/latest)

リリースに添付された `MAGLOG-バージョン-win-x64.zip` を選んでください。GitHubが自動表示する `Source code` は配布版ではありません。

## 主な機能

- PSO2 NGSのチャット・取得ログの監視と履歴表示
- Windows音声、AquesTalk10、VOICEVOX、VoiSona Talkによるチャット読み上げ
- 自分のチャットを仮想マイクへ音声出力
- 時計・日付・天気・所持メセタ・取得メセタ・討伐数カウントなどのウィジェット
- 取得メセタの集計結果表示と、討伐数の条件に応じた結果撮影
- スクリーンショットの自動撮影と整理
- フォントや各種表示のカスタマイズ
- 起動時と12時間ごとの更新通知

## 起動方法

1. 配布ZIPをフォルダーに展開します。
2. `MAGLOG.exe` を起動します。
3. 初回設定でPSO2 NGSのログフォルダーを指定します。

.NETの別途インストールは不要です。詳細は配布物に同梱する `README.txt` を確認してください。
外部音声ソフトと仮想オーディオデバイスは、使用する機能に応じて別途用意してください。

## 更新

更新がある場合、MAGLOGのダウンロードアイコンがシアンになります。クリックすると配布ページを開きます。
ダウンロードとファイルの入れ替えは手動です。変更内容は各リリースに掲載します。
